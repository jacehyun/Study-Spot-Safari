# Study Spot Safari 🐾

A student-made website that helps students in Manila find study-friendly spots — coffee shops, study hubs, and libraries — with details on schedules, location maps, and reviews.

## About

Study Spot Safari is a static, multi-page website built to help students discover Manila's best places to study. The platform features detailed listings with photos, opening hours, embedded Google Maps, customer reviews, and social media links for each location, plus a form for users to recommend new spots.

## Features

- **Home page** — Browse featured coffee shops, study hubs, and libraries via interactive Bootstrap carousels
- **Spot detail pages** — Each location has its own page with:
  - Photo and schedule (opening/closing hours)
  - Embedded Google Maps location
  - User reviews with star ratings
  - Social media links (website, Facebook, Instagram)
- **About Us page** — Project introduction and team member profiles
- **Recommendations page** — A form where users can suggest a new study spot (type, location, price range, description) and sign up for newsletter updates

## Tech Stack

- HTML5
- CSS3 (custom stylesheets per page)
- [Bootstrap 5.3.0](https://getbootstrap.com/) — carousels and layout
- Vanilla JavaScript — interactive elements (e.g. price range slider)
- Google Fonts (Poppins)
- Google Maps Embed API
